# Node declarations

**These are the representative examples the CI render tests use (§25), not an
inventory.** The estate does not live here — it lives in NinjaOne, and a real
node is described by its NinjaOne custom fields, which carry exactly the same
facts these files carry. Adding the ten-thousandth server creates no file in
this directory.

Each file exists because a CI test renders it and asserts something specific
about the result. If you are tempted to add one, ask whether you are adding a
test case or an inventory entry; only the first belongs here.
